# Fashion Image Classification using ANN vs CNN

## Overview
This project compares Artificial Neural Networks (ANN) and Convolutional Neural Networks (CNN) for classifying fashion images using the Fashion-MNIST dataset.

## Technologies Used
- Python
- NumPy
- Matplotlib
- TensorFlow / Keras
- Scikit-learn

## Dataset
- Fashion-MNIST Dataset
- 60,000 training images
- 10,000 testing images
- 10 clothing categories
- Image size: 28 × 28 pixels

## Project Workflow
1. Load and explore the dataset
2. Normalize image pixel values
3. Build and train an ANN model
4. Build and train a CNN model
5. Evaluate both models
6. Compare their performance
7. Predict clothing categories

## Model Performance

| Model | Test Accuracy |
|---|---:|
| ANN | 88.31% |
| CNN | 91.00% |

## Key Learning
- ANN and CNN architectures
- Convolution and pooling layers
- Image preprocessing
- Model training and evaluation
- Comparing deep learning models

## Conclusion
CNN achieved better test accuracy than ANN on the Fashion-MNIST dataset, demonstrating the advantage of convolutional layers in image classification.
